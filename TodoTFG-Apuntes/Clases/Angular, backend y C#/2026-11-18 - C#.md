## 2. Conceptos y patrones

- **Delegado**: un tipo que representa la firma de un método (`delegate bool ValidarNumero(int x)`). Cualquier método con esa firma (`EsPositivo`, `EsPar`…) se puede asignar a una variable de ese tipo.
- **Multidifusión** con `+=`: un delegado puede llevar varios métodos. Si se invoca directamente (`validate(x)`), se ejecutan todos, pero **solo se devuelve el resultado del último**. Por eso al principio -6 «cumplía»: el último era el de divisible por 3 y daba True.
- **`GetInvocationList()`** devuelve la lista de métodos del delegado, para recorrerla con `foreach` e invocar cada uno (`paso(x)`).
- **Acumulador con `&&`**: empieza en `true` (con `false` nunca se cumpliría). Por el **cortocircuito**, en cuanto un paso da False ya no se llaman los siguientes: con -6 solo se imprime EsPositivo.
- Tres formas de añadir un método al delegado: **método con nombre** (`Validador.EsPar`), **método anónimo** (`delegate (int n) { ... }`) y **lambda**, que puede ser de bloque (`(int n) => { ...; return r; }`) o de expresión (`(int n) => n > 20`).
- **Miembro con cuerpo de expresión**: `public static bool EsImpar(int x) => !EsPar(x);`. Reutiliza otro método.
- **Delegados genéricos de `System`**, para no tener que declarar uno propio:
  - `Func<T1, …, TResult>`: devuelve un valor (el último tipo genérico). No admite `void`.
  - `Action<T1, …>`: no devuelve nada (equivale a un `delegate void`).
  - `Predicate<T>`: un solo parámetro y devuelve `bool` (como `Func<T, bool>`).
  - Hasta 16 parámetros en Func y Action.
- Un **campo** de tipo delegado no es un **tipo**. Si `ValidarNumero` se declara como campo, no se puede usar para tipar parámetros ni variables (CS0246).
- Un delegado declarado **dentro de una clase** se usa desde fuera como `Validador.ValidarNumero`.
- Avisos del compilador vistos: CS0103 (nombre no existe), CS0246 (tipo no encontrado) y CS8618 (campo no nulo sin inicializar, con `required`).
- Herramientas del IDE: IntelliSense con documentación, CodeLens («N referencias»), resaltado de referencias, acciones rápidas (bombilla), comentarios `//` y `/* */` para apartar código de prueba, y depuración con la flecha de línea actual.

```csharp
using System;

public class Validador
{
    public delegate bool ValidarNumero(int x);

    /*Func<int, bool> ValidarNumero2;

    public static void ImprimeNumero(int x)
    {
        Console.WriteLine($"El número ingresado es: {x}");
    }

    public static bool EsNegativo(int x)
    {
        bool resultado = x < 0;
        Console.WriteLine($"El resultado de la funcion EsNegativo para {x} es: {resultado}");
        return resultado;
    }

    public static bool EsPositivo(int x)
    {
        bool resultado = x > 0;
        Console.WriteLine($"El resultado de la funcion EsPositivo para {x} es: {resultado}");
        return resultado;
    }

    public static bool EsImpar(int x) => !EsPar(x);

    public static bool EsPar(int x)
    {
        bool resultado = x % 2 == 0;
        Console.WriteLine($"El resultado de la funcion EsPar para {x} es: {resultado}");
        return resultado;
    }

    public static bool MayorACero(int x)
    {
        bool resultado = x > 0;
        Console.WriteLine($"El resultado de la funcion MayorACero para {x} es: {resultado}");
        return resultado;
    }

    public static bool Ejecutar(ValidarNumero validate, int x)
    {
        bool resultado = true;
        foreach (ValidarNumero paso in validate.GetInvocationList())
        {
            resultado = resultado && paso(x);
        }
        if (resultado)
        {
            Console.WriteLine($"El numero {x} cumple con las validaciones");
        }
        else
        {
            Console.WriteLine($"El numero {x} NO cumple con las validaciones");
        }
        return resultado;
    }
}
```
