En Classroom las actividades salen como **"Acceso a Datos"**, pero el contenido de esta parte de la asignatura es **Angular 19**: una web en TypeScript que pide los datos a una API por HTTP. Estos apuntes cubren la primera parte, la que va **del 14/10 al 05/11**, y lo básico que necesitas para seguir con formularios, signals y rutas.

<Callout type="idea" title="Si ya sabes Java">
  Angular se escribe en **TypeScript**, que se parece mucho a Java: clases, interfaces, genéricos, modificadores `private` y `protected`, decoradores (las anotaciones de Java)… Lo nuevo es la **plantilla HTML** de cada componente y cómo se enlaza con la clase.
</Callout>

## Qué se vio y cuándo

| Fecha | Proyecto | Qué se hizo |
| --- | --- | --- |
| 14/10 | `proj-lamp` (Act Eval 4, "Control de una lámpara") | Estructura de un proyecto standalone, `ng generate`, componente padre e hijo, `@if / @else`, Flexbox y encapsulación de estilos. |
| 27/10 | `angular-http` | Servicios con `HttpClient` contra JSONPlaceholder, interfaz genérica `CRUD<T, S>`, `ngOnInit` y `subscribe`, `@for ... track`, `protected` y Tailwind CSS 4. |
| 28/10 | `proj-fakestore` (Act 8) | `inject()` frente a inyección por constructor, `Observable`, property binding con `[src]` y `[alt]`, rangos semver. |
| 05/11 | `proj-game` (Act 10) | Repaso de eventos y referencias de plantilla, two-way binding con `[(ngModel)]`, class binding, `@let` y el pipe `json`. |
| 12/11 | `proj-game` | `input()` y `output()` para comunicar padre e hijo. |
