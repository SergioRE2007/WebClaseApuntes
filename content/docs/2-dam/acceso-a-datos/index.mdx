## De qué va el módulo

Aprenderás a **guardar y recuperar información** desde tus aplicaciones: ficheros de distintos formatos, bases de datos relacionales con **JDBC**, **ORM** con JPA/Hibernate, bases de datos orientadas a objetos y documentales (**MongoDB**), y el desarrollo de componentes de acceso a datos.

Módulo profesional de 2º DAM (código 0486).

## Temas

1. Manejo de ficheros: texto, binarios y acceso aleatorio
2. Ficheros XML y JSON: DOM, SAX, JAXB, Jackson
3. Conectores: JDBC
4. Herramientas de mapeo objeto-relacional: JPA e Hibernate
5. Bases de datos objeto-relacionales y orientadas a objetos
6. Bases de datos NoSQL: MongoDB
7. Desarrollo de componentes de acceso a datos
