## 2. Conceptos y patrones

**Compose**
- `@Composable` como unidad de interfaz. `@Preview` envuelto en el tema (`TipCalculatorTheme { TipCalculatorScreen() }`).
- Estado local:
  - `rememberSaveable { mutableStateOf(...) }`: sobrevive al giro de pantalla.
  - `mutableFloatStateOf` para valores `Float`.
  - `remember { TextFieldState(initialText = "0") }` para un campo de texto.
  - El delegado `by` permite usar `var x by ...` y leerlo como una variable normal.
- `Scaffold` con `innerPadding`, junto a `Modifier.consumeWindowInsets(innerPadding).padding(innerPadding)`.
- Un `Modifier` guardado en un `val` (`textFieldsModifier`, `columnModifier`) para reutilizarlo.
- `KeyboardOptions.Default.copy(keyboardType = KeyboardType.Decimal)` para que salga el teclado numérico.
- `Row` con `Arrangement.SpaceBetween` y `Alignment.CenterVertically`.
- **Componentes controlados**: `Switch(checked, onCheckedChange)` y `Slider(enabled, value, onValueChange, steps = 3, valueRange = 0f..4f)`. El valor sale del estado y el cambio se manda al ViewModel.
- `Button(enabled = ...)` con `Icon(painterResource(...), contentDescription)` y `Text` dentro.
- Pintar algo solo si se cumple una condición: `if (splitResult.isNotBlank()) Text(...)`.
- `stringResource(id = R.string.splitLabel, splitResult)`: un string con argumento de formato.

**Kotlin**
- **Referencia a función con `::`**. `viewModel::calculateSplit` pasa la función sin llamarla. `viewModel.calculateSplit` sin paréntesis no vale. La alternativa es la lambda `{ viewModel.calculateSplit() }`.
- **`data class` con valores por defecto** para el estado de la pantalla.
- `val` y `var` en el data class: se pasa de mutar un `var` a tener todos los campos `val` y crear copias.
- **`copy()` con argumentos con nombre**: crea un estado nuevo cambiando solo algunos campos. Es la base del estado inmutable.
- **`if` como expresión**: devuelve un valor y por eso **necesita `else`**.
- **Backing property**: `private var _state` (mutable e interno) y `val state` con `get() = _state` (de solo lectura hacia fuera). Es la convención `_nombre`.
- Getter personalizado (`val x: T get() = ...`).
- `when` como expresión (en la lógica antigua de la propina).

**Arquitectura**
- Separar la interfaz (el composable) de la lógica y el estado (el `ViewModel`). Los eventos (`changeTip`, `calculateSplit`) son funciones del ViewModel.
- En esta clase el ViewModel se crea **como valor por defecto del parámetro** (`= TipCalculatorViewModel()`), sin `viewModel()` ni Hilt.
