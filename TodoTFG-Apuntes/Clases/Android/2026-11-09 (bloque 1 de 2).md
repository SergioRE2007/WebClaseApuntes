**Tema de la clase:** se pasa la capa de datos de "pedir una vez" (funciones `suspend` que devuelven una lista) a **exponer un `Flow`** desde el DataSource y el Repositorio. Después, el ViewModel construye su estado con `map` + `stateIn` en vez de `MutableStateFlow` + `init`. Es el paso previo a una app *offline-first*: al final se crea la carpeta `data/local`.

## 2. Conceptos y patrones

- **Capas por feature**: `features/pokemon/data/{local, model, remote, repository}`, `di` y `ui`. La UI solo conoce la interfaz del repositorio, y el repositorio solo conoce la interfaz del DataSource.
- **Interfaz + implementación** en dos niveles: `PokemonDataSource` → `PokemonRemoteDataSource` y `PokemonRepository` → `PokemonRepositoryImpl`. Se atan con `@Binds @Singleton` en un módulo de Hilt.
- **`suspend fun` frente a `Flow`**:
  - `suspend fun readAllPokemon(): List<Pokemon>` da **una respuesta** y termina.
  - `val pokemons: Flow<List<Pokemon>>` es un **flujo** que puede emitir varias veces. Es la base para que más adelante Room emita cada vez que cambien los datos.
- **Propiedades en interfaces**: `val pokemons: Flow<...>` en la interfaz y `override val pokemons ... = ...` en la clase.
- **Constructor `flow { }`**: es un Flow *frío*. El bloque es código `suspend` que se ejecuta al recogerlo, y dentro se emite con `emit(valor)`.
- **Repositorio que delega**: `override val pokemons = _remoteDataSource.pokemons`.
- **Del `Flow` al `StateFlow` en el ViewModel**:
  - `map` transforma `List<Pokemon>` en `PokemonListScreenState.Loaded`. Los tipos genéricos se ponen explícitos (`map<List<Pokemon>, PokemonListScreenState>`) para que el resultado sea `Flow<PokemonListScreenState>` y no `Flow<Loaded>`.
  - `stateIn(scope, started, initialValue)` lo convierte en `StateFlow`.
  - `scope = viewModelScope`, no `GlobalScope`: el flujo se cancela cuando se destruye el ViewModel. `GlobalScope` no está ligado a ningún ciclo de vida y deja el trabajo vivo.
  - `SharingStarted.WhileSubscribed(5_000L)`: el flujo de arriba sigue activo 5 s después de que se vaya el último suscriptor. Así sobrevive a un giro de pantalla sin volver a pedir los datos.
  - `initialValue = Loading`: es lo que ve la pantalla hasta que llega el primer valor.
  - Con esto ya no hacen falta ni `MutableStateFlow` ni `init { viewModelScope.launch { ... } }`.
- **Pantalla con estado / pantalla sin estado** (repaso): `PokemonListScreen(viewModel = hiltViewModel(), toDetail)` lee el estado con `collectAsStateWithLifecycle()` y hace un `when` sobre la `sealed class`. Cada rama llama a la sobrecarga sin estado `PokemonListScreen(list, isLoading, toDetail)`.
- **`LazyColumn` + `items(items = list, key = { it.id })`**, `CircularProgressIndicator` y callback `toDetail(pokemon.id)` (repaso).
- **Respuesta de Retrofit**: `response.isSuccessful`, `response.body()!!` y mapeo con `toModel()`. Si falla, `null`.
- **Código generado por Dagger**: `X_Factory.get()` llama a `newInstance(_apiProvider.get())`. Es lo que hay detrás de `@Inject constructor`.
- **Git en el IDE**: elegir qué archivos o cambios entran en el commit (casillas), ver el diff, `Commit` / `Commit and Push`, mensajes `feat:` (Conventional Commits) y la inspección de avisos al hacer commit.

### `PokemonRemoteDataSource.kt`
```kotlin
import com.alanturing.pokeapp2627.features.pokemon.data.model.Pokemon
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.flow
import javax.inject.Inject

class PokemonRemoteDataSource
    @Inject constructor(
        private val _api: PokeApi
    ): PokemonDataSource {

    override val pokemons: Flow<List<Pokemon>> = flow {
        emit(readAllPokemon())
    }

    override suspend fun readAllPokemon(): List<Pokemon> {
        val response = _api.readAllPokemon()
        val pokemons = mutableListOf<Pokemon>()
        if (response.isSuccessful) {
            // TODO PARSEAR EL CUERPO A EL MODEL Pokemon
            val body = response.body()!!
            for (item in body.results) {
                val pokemon = readPokemonByName(item.name)
                pokemons.add(pokemon!!)
            }
        } else {
            // Mostrar un error!
        }
        return pokemons
    }

    override suspend fun readPokemonByName(name: String): Pokemon? {
        val response = _api.readPokemonByName(name)
        if (response.isSuccessful) {
            val body = response.body()!!
            return body.toModel()
        } else {
            return null
        }
    }

    override suspend fun readPokemonById(id: Int): Pokemon? {
        val response = _api.readPokemonById(id)
        if (response.isSuccessful) {
            val body = response.body()!!
            return body.toModel()
        } else {
            return null
        }
    }
}
```

### `PokemonListScreen.kt` (sin cambios en esta clase, sirve de repaso)
```kotlin
@Composable
fun PokemonListScreen(
    modifier: Modifier = Modifier,
    viewModel: PokemonListViewModel = hiltViewModel(),
    toDetail: (Int) -> Unit,
) {
    val state by viewModel.state.collectAsStateWithLifecycle()
    when (state) {
        PokemonListScreenState.Initial -> PokemonListScreen(modifier = modifier, toDetail = toDetail)
        is PokemonListScreenState.Loaded -> PokemonListScreen(
            modifier = modifier,
            list = (state as PokemonListScreenState.Loaded).pokemons,
            toDetail = toDetail
        )
        PokemonListScreenState.Loading -> PokemonListScreen(
            modifier = modifier, isLoading = true, toDetail = toDetail
        )
    }
}

@Composable
fun PokemonListScreen(
    modifier: Modifier = Modifier,
    list: List<Pokemon> = listOf(),
    isLoading: Boolean = false,
    toDetail: (Int) -> Unit,
) {
    if (isLoading) { CircularProgressIndicator() }
    if (list.isNotEmpty()) {
        LazyColumn {
            items(items = list, key = { pokemon -> pokemon.id }) { pokemon ->
                PokemonListItem(
                    modifier = Modifier.fillMaxWidth().height(60.dp),
                    name = pokemon.name,
                    imageUrl = pokemon.pokemonImageUrl,
                    toDetail = { toDetail(pokemon.id) }
                )
            }
        }
    }
}
```
