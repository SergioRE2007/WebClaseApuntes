## 2. Conceptos
- **Ramas locales:** `main` y `vercel-deployment`.
- **Ramas remotas:** `origin/main` y `origin/vercel-deployment`.
- **Tags de versión:**
  - `v1.0.0`: "v1.0.0 - Producción y documentación".
  - `v1.1.0`: "feat: Add media upload with Cloudinary integration (v1.1.0)".
- **Commits con prefijo:** se ve `doc: actualizar CHANGELOG con v1.1.0` en `main`, además del `feat:` del tag anterior.
- Se puede hacer checkout de una rama o de un tag desde el propio IDE, para ver el proyecto tal como estaba en cada versión.
- Junto al `CHANGELOG.md` (que tiene secciones como "v0.3.0 - PostgreSQL + Docker con Prisma"), esto deja ver que el profesor publica el proyecto paso a paso, de v0.x a 1.0 y luego a 1.1.
