Un **array** es una estructura que guarda varios valores del mismo tipo en posiciones consecutivas...

<Callout type="idea" title="Lo que vas a aprender">
  - Declarar y crear arrays.
  - Recorrerlos con `for` y `for-each`.
  - Usar la clase `Arrays`.
</Callout>

## Declarar y crear un array

Explicación...

```java title="Ejemplo.java"
int[] notas = new int[5];
String[] nombres = {"Ana", "Luis", "Marta"};
```

<Callout type="warn" title="Los índices empiezan en 0">
  Acceder a `notas[5]` en un array de 5 posiciones lanza `ArrayIndexOutOfBoundsException`.
</Callout>

## Recorrer un array

<Tabs items={['for clásico', 'for-each']}>
  <Tab value="for clásico">

```java
for (int i = 0; i < notas.length; i++) {
    System.out.println(notas[i]);
}
```

  </Tab>
  <Tab value="for-each">

```java
for (int nota : notas) {
    System.out.println(nota);
}
```

  </Tab>
</Tabs>

<Terminal titulo="bash">
{`$ java Ejemplo

5
9`}
</Terminal>

## Ejercicios

<Ejercicio titulo="Nota máxima" dificultad="facil">
  Dado un array de notas, muestra la nota más alta.

  <Pista>Guarda la primera nota como máximo provisional y recorre el resto.</Pista>

  <Solucion>

```java
int max = notas[0];
for (int nota : notas) {
    if (nota > max) max = nota;
}
System.out.println(max);
```

  </Solucion>
</Ejercicio>
