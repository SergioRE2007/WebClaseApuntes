## De qué va el módulo

Aprenderás las herramientas y técnicas que usa un desarrollador profesional: **IDE**, **control de versiones con Git**, depuración, **pruebas unitarias** (JUnit), refactorización, documentación del código y **diagramas UML** de clases y de comportamiento.

Módulo profesional de 1º DAM (código 0487).

## Temas

1. Desarrollo de software: ciclo de vida y metodologías (incluidas las ágiles)
2. Instalación y uso de entornos de desarrollo (IntelliJ IDEA, Eclipse, VS Code)
3. Control de versiones con Git y GitHub
4. Depuración de programas
5. Diseño y realización de pruebas: JUnit
6. Optimización y refactorización del código
7. Documentación: Javadoc y Markdown
8. Diagramas de clases UML
9. Diagramas de comportamiento: casos de uso, secuencia y actividad
