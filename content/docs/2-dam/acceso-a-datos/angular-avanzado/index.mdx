## Cómo leer estos apuntes

El código de clase sale de capturas de los vídeos, así que verás cuatro marcas:

- **"Visto en clase el …"**: cuándo y en qué proyecto se vio algo.
- La etiqueta de **no dado en clase**: lo que no salió en las clases (la forma estándar de hacerlo, de las guías o de los requisitos). Si lo usas en la defensa, di que lo has buscado tú.
- **[dudoso]**: algo que no se leía bien en las capturas. Se deja como estaba, sin corregir.
- **"Esto no se llega a ver en clase"**: código que no sale en las capturas. No se rellena.

Las guías de Angular que se usaron como apoyo son una copia de [guides-angular](https://github.com/hokahey007/guides-angular); el código de ejemplo de cada una está en [codebase-angular](https://github.com/hokahey007/codebase-angular). Aquí se resumen con nuestras palabras y se enlaza al original.

<Callout title="Versiones">
  Todo es Angular 19 (`ng-version` 19.2.25, paquetes en `^19.2.0`, TypeScript `~5.7.2`) y `json-server@0.17.4`. Muchas cosas de internet son de Angular 20 o posterior, o de JSON Server 1.x, y no se escriben igual.
</Callout>
