## De qué va el módulo

Diseñarás y programarás **interfaces gráficas de usuario** (con herramientas como JavaFX, Compose o tecnologías web), aplicando principios de **usabilidad y accesibilidad**. También verás generación de informes, componentes reutilizables, documentación, pruebas y empaquetado/distribución de aplicaciones.

Módulo profesional de 2º DAM (código 0488).

## Temas

1. Confección de interfaces de usuario
2. Generación de interfaces a partir de documentos XML
3. Creación de componentes visuales
4. Usabilidad y accesibilidad
5. Confección de informes
6. Documentación de aplicaciones
7. Distribución de aplicaciones
8. Realización de pruebas
