## 2. Conceptos y patrones

- **Rutas tipadas**: una `sealed class Route` marcada con `@Serializable`. Los destinos sin datos son `object` y los que llevan datos son `class` con propiedades (`TaskDetail(val id: Int)`).
- **Plugin de serialización de Kotlin**: la teoría de Moodle dice que, en Compose, Navigation lo necesita para las rutas tipadas.
- **NavController**: se crea con `val controller = rememberNavController()`, siempre con `=` y no con `by`. `NavHostController` no tiene `getValue`, así que no sirve como delegado. El profesor lo enseña provocando el error, y es una diferencia clave entre `=` y `by`.
- **NavHost**: los parámetros obligatorios son `navController` y `startDestination`. Este último es de tipo `Any`, así que acepta un objeto de ruta. El último parámetro es `builder: NavGraphBuilder.() -> Unit`, una lambda con receptor, y dentro van los `composable<T> { }`. Según la documentación, el builder se recuerda y no cambia.
- **Un `composable<Route.X>` por pantalla**, y dentro se llama al Screen.
- **La pantalla no conoce el navController**: recibe callbacks del tipo `() -> Unit` (`toCreate`), y el NavHost decide a dónde ir con `controller.navigate(Route.TaskCreate)`.
- **Navegar en vez de usar un `if` con estado local**: el `isCreatingTask` con `if/else` que mostraba `TaskCreateScreen` se sustituye por la navegación.
- **Argumentos**: según la documentación, `backStackEntry.toRoute<T>()` o `savedStateHandle.toRoute<T>()`.
- **Valores por defecto en los parámetros** (`repository: TaskRepository = TaskRepositoryInMemory()`). Es un apaño temporal para que compile mientras no hay ViewModel. El profesor deja un `// TODO Cambiar a viewModel` y otro `// TODO COMO HAGO ESTO QUE SEA OBSERVABLE?`.
- **No se puede instanciar una interfaz** (`TaskRepository()` da error). Hay que usar la implementación.
- **Kotlin**: tipos nulables `Int?`, llamada segura `?.let { }`, plantillas de texto `"Tarea $id"` y `let` como función genérica `<T, R>`.
- **Convención de Compose**: `modifier: Modifier = Modifier` como parámetro.
- **IDE**: autocompletado, documentación rápida, Alt+Mayús+Intro para importar y Run 'app' con Mayús+F10.
- **Compilación**: KSP (`kspDebugKotlin`) y las tareas de Hilt (`hiltCollectClassesDebug`, `hiltAggregateDepsDebug`, `hiltJavaCompileDebug`) generan código.

import androidx.compose.runtime.Composable
import androidx.navigation.compose.NavHost
import androidx.navigation.compose.composable
import androidx.navigation.compose.rememberNavController
import com.alanturing.todoapp.ui.TaskListScreen

@Composable
fun ToDoNavHost() {
    val controller = rememberNavController()

    NavHost(
        navController = controller,
        startDestination = Route.TaskList

        composable<Route.TaskList> {
            TaskListScreen(
                toCreate = {
                    controller.navigate(Route.TaskCreate)
