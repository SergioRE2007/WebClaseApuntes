## De qué va el módulo

Conocerás cómo funciona por dentro un ordenador y cómo se instalan, configuran y administran los **sistemas operativos** (Windows y GNU/Linux), además de los fundamentos de **redes** y la automatización con scripts. Es la base para desplegar y ejecutar tus aplicaciones.

Módulo profesional de 1º DAM (código 0483).

## Temas

1. Componentes físicos de un sistema informático
2. Sistemas operativos: funciones, tipos e instalación
3. Gestión de usuarios, grupos y permisos
4. Sistema de ficheros y gestión de software
5. Administración de GNU/Linux desde la terminal
6. Administración de Windows y PowerShell
7. Redes: modelos OSI y TCP/IP, direccionamiento IP y servicios
8. Virtualización y contenedores
9. Scripting y automatización de tareas
