## De qué va

Diseñar, programar y desplegar **servicios y APIs**: cómo se modela una API, cómo se implementa en el servidor, cómo se protege y documenta, y cómo se pone en marcha en una infraestructura real.

## Temas

1. HTTP y diseño de APIs REST
2. Implementación de servicios backend
3. Persistencia y acceso a datos desde la API
4. Autenticación y autorización (tokens, JWT)
5. Documentación y pruebas de APIs (OpenAPI, Postman)
6. Contenedores y despliegue de servicios
