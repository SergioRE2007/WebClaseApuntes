## 2. Conceptos y patrones

- **Delegado**: es un tipo que fija la firma de un método. En los apuntes se define como *"un contrato entre el emisor y el receptor"* que *"determina la firma de un gestor de eventos en el receptor y puede contener muchos punteros de métodos"*.
- **Evento**: `public event TipoDelegado Nombre;`. Por convención, el nombre empieza por `On` (`OnSegundo`).
- **Emisor y receptor** (publicador y suscriptor): la clase que lanza el evento (`Reloj`, `AsistenteDescarga`) no sabe quién lo escucha. Los receptores (`Program`, `ServicioDescomprimir`, `ServicioNotificación`) se suscriben.
- **Disparar el evento**: se hace dentro de la clase emisora con `Evento.Invoke()`. El evento no se lanza solo: tiene que pasar algo, y aquí es el bucle de `Iniciar()` con `Thread.Sleep(1000)`.
- **Tres formas de suscribirse con `+=`**:
  1. Un método con nombre (*method group*), sin paréntesis: `+= ImprimeHaPasadoUnSegundo;`
  2. Un método anónimo: `+= delegate () { ... };`
  3. Una lambda: `+= () => { ... };`
- **Darse de baja con `-=`**: se puede hacer incluso desde dentro de otro manejador mientras el programa se está ejecutando.
- **Varios manejadores en un mismo evento**: se ejecutan todos, en el orden en que se suscribieron.
- **Captura de variables (closure)**: una lambda o una función local *no estática* pueden leer y cambiar variables locales del código de nivel superior (`segundo`). Una función local `static` no puede (CS8421).
- **Ámbito**: en un `Program.cs` con *top-level statements* no se pueden declarar dos variables con el mismo nombre en ámbitos anidados (CS0136).
- **Nulabilidad**: CS8618 avisa de que el evento puede ser `null` al salir del constructor. Si nadie se ha suscrito, `OnSegundo.Invoke()` lanzaría `NullReferenceException`. En clase la advertencia se queda sin resolver. La forma habitual es `OnSegundo?.Invoke();` o declararlo como `event CadaSegundoHandler? OnSegundo;`, pero esto no se vio en las capturas.
- **Patrón estándar del PDF**: manejador con la firma `(object sender, EventArgs e)` y `this` como `sender` (*"el objeto que lanza el evento soy yo mismo"*). Un método protegido `OnSegundoCambiado()` lanza el evento `SegundoCambiado`.
- Visual Studio: IntelliSense, TAB para generar el manejador, CodeLens ("N referencias"), información rápida con Ctrl+. y la Lista de errores. Ctrl+F5 ejecuta sin depurar.

## 3. Código de ejemplo del profesor

**Reloj.cs** (versión final):
```csharp
using System;

public class Reloj
{
    public delegate void CadaSegundoHandler();
    public event CadaSegundoHandler OnSegundo;

    public void Iniciar()
    {
        while (true)
        {
            Thread.Sleep(1000);
            OnSegundo.Invoke();
        }
    }
}
```

**Program.cs** (versión final, minuto 11:52):
```csharp
// See https://aka.ms/new-console-template for more information

int segundo = 0;
Reloj reloj = new Reloj();
reloj.OnSegundo += ImprimeHaPasadoUnSegundo;
reloj.OnSegundo += () =>
{
    segundo = segundo + 1;
    Console.WriteLine($"Han pasado {segundo} segundos");
    if (segundo == 20)
    {
        reloj.OnSegundo -= ImprimeHaPasadoUnSegundo;
    }
};

reloj.Iniciar();

void ImprimeHaPasadoUnSegundo()
{
    Console.WriteLine("Ha pasado un segundo");
}
```
Salida: "Ha pasado un segundo" y "Han pasado 1 segundos" alternados hasta el 20. Desde el 21 solo sale "Han pasado N segundos".
