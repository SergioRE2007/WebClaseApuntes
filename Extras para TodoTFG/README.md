# Extras para los apuntes

Archivos para añadir a la carpeta de apuntes de clase. Van en la raíz, junto a "Lo dado en clase de …".

| Archivo | Qué tiene |
|---|---|
| `Requisitos y dónde se dieron.md` | Cada requisito del proyecto (Android, backend y Angular), en qué clase salió y qué falta. Al final, lo que os pueden pedir en la defensa. |
| `Lo que falta por dar - Android.md` | Cómo hacer lo que piden y no se ha dado: intent implícito, inglés y español, Room con relaciones, offline first, DataStore en el tema, llamar a vuestra API, token, barra inferior… |
| `Lo que falta por dar - backend y Angular.md` | Seed, listado con búsqueda, filtro, orden y paginación, transacción, errores HTTP, CORS, token, y el listado de Angular conectado a la API. |
| `Errores típicos.md` | Errores con su mensaje, por qué pasan y cómo se arreglan. Los que tienen 🎓 salieron en clase. |
| `Glosario.md` | Las palabras raras de clase, en una o dos líneas. |
| `Chuleta de Compose.md` | Lo más básico de Compose (`Text`, `Column`, `Modifier`…). |
| `Contexto para la web.md` | Para pasárselo a quien haga la web con los apuntes. |

El código de los dos archivos "Lo que falta por dar" **no es de clase**, pero está compilado con las versiones de clase (Room 3, Retrofit 3, Prisma 6, Zod 4, Express 5 y Angular 19). No se ha probado ejecutándolo.

Si añadís estos archivos a la carpeta, añadid también esta tabla al `README.md` de la carpeta de apuntes.
