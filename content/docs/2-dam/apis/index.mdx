En clase, esta asignatura ha sido **el backend**: montar desde cero una API REST con **Node.js, Express 5 y TypeScript**, guardar los datos en **PostgreSQL** con **Prisma 6**, validar lo que llega con **Zod 4**, añadir registro y login con JWT, y terminar con logs, tests, Docker y Swagger. Es la API que luego consume tu web de Angular y tu app Android.

Los apuntes están en dos bloques: lo que se vio en clase y lo que te falta para el proyecto.

## Para el proyecto intermodular

El proyecto pide un backend con varias entidades relacionadas, seed, búsqueda y paginación en el servidor, una operación con transacción y una API que Angular pueda consumir. Parte de eso se dio en clase y parte no. En [Backend para el proyecto](/docs/2-dam/apis/backend-proyecto) tienes cada requisito con su estado y la página que lo explica, y todo lo que no se dio va marcado.
