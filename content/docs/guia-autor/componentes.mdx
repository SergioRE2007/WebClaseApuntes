## Componentes interactivos de DAM Apuntes

### Quiz (test)

Un test que se responde pregunta a pregunta, con corrección inmediata, explicación, puntuación final, botón de reintentar y celebración si aciertas todas. Hay tres tipos de pregunta:

- **Opciones** (por defecto): hijos `<Opcion>`, marca la buena con `correcta`. Si marcas **más de una** correcta, la pregunta pasa a ser de respuesta múltiple automáticamente (casillas + botón Comprobar).
- **Verdadero/falso**: `tipo="vf"` y `respuesta={true}` o `respuesta={false}`.
- **Texto**: `tipo="texto"` y `respuesta="..."` (o una lista de respuestas válidas). Ideal para "¿qué imprime este código?".

<Quiz titulo="Quiz de ejemplo" descripcion="Así lo verá el alumnado">
  <Pregunta enunciado="¿Qué palabra clave crea un objeto en Java?" explicacion="`new` reserva memoria, ejecuta el constructor y devuelve la referencia.">
    <Opcion>`class`</Opcion>
    <Opcion correcta>`new`</Opcion>
    <Opcion>`this`</Opcion>
  </Pregunta>
  <Pregunta enunciado="¿Cuáles son tipos primitivos?" explicacion="`String` es una clase, no un tipo primitivo.">
    <Opcion correcta>`int`</Opcion>
    <Opcion correcta>`boolean`</Opcion>
    <Opcion>`String`</Opcion>
  </Pregunta>
  <Pregunta tipo="vf" enunciado="`main` tiene que ser `static`." respuesta={true} explicacion="La JVM lo llama sin crear ningún objeto." />
  <Pregunta tipo="texto" enunciado="¿Qué imprime `System.out.println(7 / 2);`?" respuesta="3" explicacion="Dividir dos `int` da un `int`: se descarta la parte decimal." />
</Quiz>

### Flashcards (tarjetas de repaso)

Mazo de tarjetas que se giran con animación 3D. El alumno marca cada una como "me la sé" o "repasar", puede barajar y repasar solo las marcadas. Teclado: espacio gira, flechas mueven, `S` y `R` marcan.

<Flashcards titulo="Mazo de ejemplo">
  <Tarjeta frente="¿Qué es la JVM?">La **Java Virtual Machine**: ejecuta el *bytecode* (`.class`) en cualquier sistema operativo.</Tarjeta>
  <Tarjeta frente="¿Qué genera `javac`?">Ficheros `.class` con *bytecode* a partir de los `.java`.</Tarjeta>
  <Tarjeta frente="JDK frente a JRE">El **JDK** incluye herramientas de desarrollo (compilador…); el **JRE** solo lo necesario para ejecutar.</Tarjeta>
</Flashcards>

### Ejercicio, Pista y Solucion

Enunciado con pistas que se revelan de una en una, solución oculta (con un "¿seguro?" antes de mostrarla) y un botón para pedir ayuda al Tutor DAM.

<Ejercicio titulo="Par o impar" dificultad="facil">
  Escribe un programa que lea un número entero y diga si es par o impar.

  <Pista>Un número es par si el resto de dividirlo entre 2 es 0.</Pista>
  <Pista>El operador resto en Java es `%`.</Pista>

  <Solucion>

```java
Scanner sc = new Scanner(System.in);
int n = sc.nextInt();
System.out.println(n % 2 == 0 ? "Par" : "Impar");
```

  </Solucion>
</Ejercicio>

### CompletarCodigo (rellenar huecos)

Código con huecos que el alumno rellena; comprueba cada hueco y puede ver la solución. Marca cada hueco con `[[respuesta]]` y, si hay varias respuestas válidas, sepáralas con `|`: `[[JOIN|INNER JOIN]]`.

<CompletarCodigo
  titulo="Bucle for"
  enunciado="Completa el bucle para imprimir los números del 1 al 10."
  codigo={`for (int i = [[1]]; i [[<=]] 10; [[i++|++i|i += 1]]) {
    System.out.[[println]](i);
}`}
/>

```mdx
<CompletarCodigo
  titulo="Bucle for"
  enunciado="Completa el bucle para imprimir los números del 1 al 10."
  lenguaje="java"

    System.out.[[println]](i);

```

### Terminal

Salida de consola con estilo de ventana. Las líneas que empiezan por un *prompt* (`$ `, `> `, `PS> `, `mysql> `, `jshell> `…) se muestran como comandos y el resto como salida. El botón copia solo los comandos.

<Terminal titulo="bash">
{`$ javac Main.java
$ java Main
Hola, mundo`}
</Terminal>
