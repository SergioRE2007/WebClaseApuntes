## De qué va el módulo

Trabajarás con lenguajes de marcas para **estructurar, validar y transformar información**: HTML y CSS para la web, XML con sus esquemas (DTD, XSD), consulta con XPath y XQuery, transformación con XSLT, y formatos como JSON. También se presentan los sistemas de gestión de información (ERP, CRM).

Módulo profesional de 1º DAM (código 0373).

## Temas

1. Características de los lenguajes de marcas
2. HTML: estructura y semántica
3. CSS: selectores, modelo de caja, Flexbox y Grid
4. XML: sintaxis y documentos bien formados
5. Validación: DTD y XML Schema (XSD)
6. Consulta de XML: XPath y XQuery
7. Transformación: XSLT
8. JSON y sindicación de contenidos
9. Sistemas de gestión de información (ERP, CRM)
