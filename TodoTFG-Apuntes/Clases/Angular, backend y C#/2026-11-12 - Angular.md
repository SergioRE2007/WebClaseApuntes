## 2. Conceptos y patrones

**Formularios template-driven (Act 10)**
- Referencia de plantilla `#gameForm="ngForm"` y envío con `(ngSubmit)`. El documento lo dice así: "No utilices `(click)="saveGame()"` como mecanismo principal de envío. El formulario debe trabajar con ngSubmit".
- `novalidate` desactiva la validación HTML nativa del navegador. Valida Angular.
- `[(ngModel)]` hace el enlace en los dos sentidos con `this.game.x`. Cada control tiene su referencia (`#title="ngModel"`), con `required`, `minlength`, `min` y `max` en la plantilla.
- Estados del control y del formulario: `invalid`, `valid`, `touched`, `dirty`, `submitted`, `pristine` y `untouched`. Los errores se leen con `title.errors?.['required']` y `['minlength']`, `['min']` o `['max']`.
- `@let` guarda una condición en la plantilla. Con `[class.invalid-control]` se marca el campo.
- Indicador global con `@if (gameForm.invalid && gameForm.dirty)`.
- **Cambio de criterio en clase:** el documento (apartado 22) propone desactivar Guardar con `[disabled]="gameForm.invalid"`. En el código se quitó, y es el componente el que filtra con `if (form.invalid) return;`. La Act 11 también pide no desactivarlo con `[disabled]`.
- `form.resetForm()` reinicia los valores y el estado del formulario (vuelve a pristine y untouched). Vaciar el objeto solo cambia los valores.
- Para editar se hace una copia con spread (`{ ...game }`), así no se toca el objeto de la lista.

**Comunicación padre-hijo y ciclo de vida**
- Componentes standalone con `imports: [FormsModule, JsonPipe]`.
- El servicio se inyecta con `inject(GameService)`.
- `editGame = input.required<Game | undefined>()` es la entrada y `actualizaGames = output<Game>()` es la salida. El padre usa `[editGame]="this.editGame"` y `(actualizaGames)="onActualizaGames($event)"`.
- `ngOnChanges(changes: SimpleChanges)` reacciona cuando el padre manda un juego: copia `currentValue` en `this.game` y pone `edit = true`.
- `@for (game of this.games; track game.id)` y el pipe `json` para pintar los objetos mientras se depura.

**Servicio HTTP**
- El componente no hace peticiones: se encarga `GameService` con `HttpClient`.
- `get<T>`, `post<T>` y `put<T>`. Paginación en el servidor con `?_page=&_limit=` (JSON Server) y `observe: 'response'` para recibir la respuesta completa.
- `update` lanza un `Error` si el juego no tiene `id`.

**Alta o edición: el problema de la clase**
- Hay dos formas de decidir entre POST y PUT: con la bandera `this.edit` o con `this.game.id`.
- Al usar `this.game.id`, se vio que después de editar el `id` se quedaba en `this.game`, porque `resetForm()` solo limpia los campos que tienen `ngModel` y el `id` no es uno de ellos. Esto es una interpretación de lo que se ve: el siguiente alta se habría tratado como edición. Se probó a quitarlo con `delete this.game.id`.
- Al final se dejó la bandera `this.edit`, que se vuelve a poner a `false` después de actualizar.

**Depuración**
- Breakpoints en VS Code y en DevTools → Sources (en `.ts` y en `.html`). Se inspeccionan `this.game`, el Scope (`_CrudComponent`, `_NgForm`) y el Call Stack.

**Formularios reactivos (Act 11, solo leído)**
- `FormGroup` y `FormControl` con `nonNullable: true` y `validators`.
- `FormsModule` da `ngModel` y `ngForm`. `ReactiveFormsModule` da `[formGroup]` y `formControlName`. En este formulario no hace falta importar los dos.
- Con `[formGroup]`, la referencia `#form="ngForm"` deja de ser un `NgForm`: pasa a ser un `FormGroupDirective`. `form.submitted` sigue funcionando.
- `formControlName` se busca por la clave dentro del `FormGroup`.
- Tabla de controles:

| Control | Valor inicial | Validadores |
|---|---|---|
| title | `''` | required, minLength(3) |
| genre | `''` | required |
| platform | `''` | required |
| price | `0` | required, min(0.01) |
| stock | `0` | required, min(0), pattern de entero (`/^\d+$/`) |

- El documento avisa de que `type="number"` y `step="1"` no sustituyen a la validación de Angular.

## 3. Código del profesor (reconstruido)

**crud.component.ts**
```ts
import { Component, inject, input, OnChanges, output, SimpleChanges } from '@angular/core';
import { FormsModule, NgForm } from '@angular/forms';
import { GameService } from '../services/game.service';
import { Game } from '../models/game';
import { JsonPipe } from '@angular/common';

@Component({
  selector: 'app-crud',
  imports: [FormsModule, JsonPipe],
  templateUrl: './crud.component.html',
  styleUrl: './crud.component.css'
})
export class CrudComponent implements OnChanges {
  private gameService = inject(GameService);

  edit = false;
  editGame = input.required<Game | undefined>();

  ngOnChanges(changes: SimpleChanges): void {
    if (changes['editGame']?.currentValue) {
      this.game = { ...changes['editGame'].currentValue };
      this.edit = true;
    }
  }

  actualizaGames = output<Game>();

  game: Game = { title: '', genre: '', platform: '', price: 0, stock: 0 };

  onSaveGame(form: NgForm) {
    if (form.invalid) {
      return;
    }
    //Traza...
    console.log(this.game);
    console.log(form.value);

    if (this.edit) {
      //if (this.game.id) {}
      this.gameService.update(this.game).subscribe(gameUpdated => {
        console.log(`Game updated: ${gameUpdated}`);
        form.resetForm();
        //delete this.game.id;
        this.edit = false;
        this.actualizaGames.emit(gameUpdated);
      });
    } else {
      //CREAR - POST
      this.gameService.create(this.game).subscribe(gameSaved => {
        console.log(`Game saved: ${gameSaved}`);
        form.resetForm();
        this.actualizaGames.emit(gameSaved);
      });
    }
  }
}
```

**game.service.ts** (fragmento)
```ts
getGameById(id: number): Observable<Game> {
  return this.http.get<Game>(`${this.apiUrl}/${id}`);
}

getGamesPyPage(pag: number, tamPage: number) {
  return this.http.get<Game[]>(this.apiUrl + `?_page=${pag}&_limit=${tamPage}`, {
    observe: 'response'
  });
}

create(game: Game) {
  return this.http.post<Game>(this.apiUrl, game);
}

update(game: Game) {
  if (game.id) {
    return this.http.put<Game>(this.apiUrl + `/${game.id}`, game);
  }
  throw new Error(`Game a actualizar sin id = ${game}`);
}
```

## 4. Librerías, comandos y versiones
- `@angular/core`: `Component`, `inject`, `input`, `output`, `OnChanges`, `SimpleChanges` y la sintaxis `@for`, `@if` y `@let`.
- `@angular/forms`: `FormsModule`, `NgForm`, `ngModel` y `ngSubmit`. En la Act 11, `ReactiveFormsModule`, `FormGroup`, `FormControl`, `Validators` y `FormGroupDirective`.
- `@angular/common`: `JsonPipe`. `@angular/common/http`: `HttpClient`. `rxjs`: `Observable` y `subscribe`.
- JSON Server (con `_page` y `_limit`) y faker para generar datos con un script (`db.js` y `export-json.js`, del anuncio).
- Git (Act 11, paso 3):

- `ng serve` como punto de control. Errores típicos que cita la guía: "Cannot find control" y "Can't bind to … known property".
