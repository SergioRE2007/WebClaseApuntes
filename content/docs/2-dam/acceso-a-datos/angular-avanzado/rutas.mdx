Una app Angular es una **SPA** (*single page application*): el navegador carga un solo `index.html` y, al pulsar un enlace, el **Router** cambia el componente que se ve sin recargar la página. La URL cambia igualmente, así que se puede compartir, recargar y usar el botón Atrás.

El 19/11 se montó un "Portal educativo" (`proyecto-rutas`) siguiendo el enunciado de la **Act 12**, *"Rutas Parametros Redirecciones LazyLoading"*. Esta página recoge lo que se escribió en clase. Lo que solo salió en el enunciado y en la solución desplegada (parámetros `:id`, *query params*, comodín `**`, `loadChildren`) está en [Parámetros, guards y lazy loading](/docs/2-dam/acceso-a-datos/angular-avanzado/rutas-parametros-guards).

<Callout type="idea" title="Lo que vas a aprender">
  - Registrar el router con `provideRouter(routes)` y declarar las rutas.
  - Redirigir la ruta vacía con `redirectTo` y `pathMatch: 'full'`.
  - Navegar con `routerLink` y pintar la página en `<router-outlet />`.
  - Anidar rutas con `children` y un segundo outlet, y distinguir enlaces relativos y absolutos.
  - Marcar el enlace activo con `routerLinkActive` y navegar desde TypeScript con `Router`.
</Callout>

## Registrar el router

```ts title="src/app/app.config.ts"
import { ApplicationConfig, provideZoneChangeDetection } from '@angular/core';
import { provideRouter } from '@angular/router';

import { routes } from './app.routes';

export const appConfig: ApplicationConfig = {
  providers: [provideZoneChangeDetection({ eventCoalescing: true }), provideRouter(routes)]
};
```

- `provideRouter(routes)` registra el router en una app *standalone*. Viene así de serie al crear el proyecto.
- `routes` se importa de `./app.routes`. Su tipo es `Routes`, que no es más que `Route[]`: un array de objetos, uno por ruta. El profesor lo dibujó en Excalidraw encima del código.
- En `index.html`, `<base href="/">` le dice al router desde dónde se cuentan las rutas.

## Declarar las rutas

```ts title="src/app/app.routes.ts"
import { Routes } from '@angular/router';
import { InicioComponent } from './pages/inicio/inicio.component';
import { AulaComponent } from './pages/aula/aula.component';
import { AyudaComponent } from './pages/ayuda/ayuda.component';

export const routes: Routes = [
  { path: '', redirectTo: '/inicio', pathMatch: 'full' },
  { path: 'inicio', component: InicioComponent },
  { path: 'aula', component: AulaComponent },
  { path: 'ayuda', component: AyudaComponent }
];
```

- Cada ruta une un `path` con el `component` que se pinta.
- **El `path` va sin barra inicial**: `'inicio'`, no `'/inicio'`. La barra va en los enlaces.
- La ruta vacía `''` es la portada (`localhost:4200/`). Con `redirectTo` manda a `/inicio`.
- **`pathMatch: 'full'`** hace que solo coincida si la URL **entera** está vacía. Sin él, `''` sería prefijo de cualquier URL.
- En el enunciado pone `redirectTo: 'inicio'` (sin barra) y en el código del profesor `'/inicio'`. En la raíz valen las dos.
- El router prueba las rutas **en orden** y se queda con la primera que coincide.

## Enlaces y router-outlet

```html title="src/app/app.component.html"
<h1>Portal educativo</h1>
<nav>
  <a routerLink="/inicio">Inicio</a>
  <a routerLink="/aula">Aula</a>
  <a routerLink="/ayuda">Ayuda</a>
</nav>
<hr>
<router-outlet />
```

```ts title="src/app/app.component.ts"
import { Component } from '@angular/core';
import { RouterOutlet, RouterLink, RouterLinkActive } from '@angular/router';

@Component({
  selector: 'app-root',
  imports: [RouterOutlet, RouterLink, RouterLinkActive],
  templateUrl: './app.component.html',
  styleUrl: './app.component.css'
})
export class AppComponent {
  title = 'proyecto-rutas';
}
```

- **`routerLink`** sustituye a `href`: navega sin recargar la página. Según el tooltip acepta `string | any[] | UrlTree | null`.
- **`<router-outlet />`** es el hueco donde se pinta el componente de la ruta activa. En la pizarra quedó anotado: *"En este tag de router-outlet se carga el componente asociado a la ruta"*. Lo que está fuera del outlet (el título y el menú) se ve en todas las páginas.
- Como el componente es *standalone*, cada directiva del router que use la plantilla tiene que estar en su `imports`. Sin `RouterOutlet`, `<router-outlet />` es un elemento desconocido y no compila.
- En la captura del primer bloque del 19/11 solo se ve `RouterOutlet` en el array, con el cursor dentro <Dudoso nota="Las tres directivas sí se ven juntas en el AulaComponent y en el AppComponent del segundo bloque." />.

<Callout type="idea" title="Sin barra en path, con barra en routerLink">
  En `app.routes.ts` se escribe `path: 'inicio'`; en el enlace, `routerLink="/inicio"`. La barra del enlace significa "desde la raíz" (enlace **absoluto**). El profesor unió con flechas cada `routerLink` con su `path` en la pizarra para que se viera la correspondencia.
</Callout>

Los enlaces salían pegados, así que se añadió `a { margin-left: 1rem; }` en `app.component.css`. En el segundo bloque esa regla se movió a **`src/styles.css`**, la hoja global: lo que va en el CSS de un componente solo afecta a ese componente, y los enlaces del aula (que es otro componente) no la recibían.

## Rutas hijas

<DeClase fecha="19/11" proyecto="proyecto-rutas" nota="Fase II del enunciado" />

El Aula tiene dos secciones, Materiales y Avisos, que se pintan **dentro** de la página del Aula, debajo de su propio menú. Para eso, `aula` pasa a ser una ruta padre con `children`:

```ts title="src/app/app.routes.ts (con rutas hijas)"
export const routes: Routes = [
  { path: '', redirectTo: '/inicio', pathMatch: 'full' },
  { path: 'inicio', component: InicioComponent },
  { path: 'aula', component: AulaComponent,
    children: [
      // ruta -> /aula/materiales
      { path: 'materiales', component: MaterialesComponent },
      // ruta -> /aula/avisos
      { path: 'avisos', component: AvisosComponent }
    ]
  },
  { path: 'ayuda', component: AyudaComponent }
];
```

- La URL de una hija es la del padre más la suya: `/aula` + `materiales` = `/aula/materiales`.
- El padre (`AulaComponent`) necesita **su propio `<router-outlet />`**. El outlet de `AppComponent` pinta el Aula y el outlet del Aula pinta Materiales o Avisos.

```html title="src/app/pages/aula/aula.component.html"
<h2>Aula virtual</h2>
<nav>
  <a routerLinkActive="class-css-activo" [routerLinkActiveOptions]="{exact: true}" routerLink="materiales">Materiales</a>
  <a routerLinkActive="class-css-activo" [routerLinkActiveOptions]="{exact: true}" routerLink="avisos">Avisos</a>
</nav>
<hr>
<router-outlet />
```

```ts title="src/app/pages/aula/aula.component.ts"
import { Component } from '@angular/core';
import { RouterOutlet, RouterLink, RouterLinkActive } from '@angular/router';

@Component({
  selector: 'app-aula',
  imports: [RouterOutlet, RouterLink, RouterLinkActive],
  templateUrl: './aula.component.html',
  styleUrl: './aula.component.css'
})
export class AulaComponent {}
```

Al principio el editor marcaba error en esta plantilla porque `AulaComponent` no importaba las directivas: cada componente importa lo suyo, aunque el padre ya las tenga. En el navegador, el texto "avisos works!" sale **dentro** de la página del Aula.

### Enlaces relativos y absolutos

| Enlace | Tipo | A dónde va |
| --- | --- | --- |
| `routerLink="materiales"` (en el Aula) | Relativo | Cuelga de la ruta del componente: `/aula/materiales` |
| `routerLink="/aula/materiales"` (en el menú principal) | Absoluto | Desde la raíz: `/aula/materiales` |

Los dos llegan al mismo sitio. El relativo es el que se usa dentro del Aula (si mañana el Aula cambia de URL, sus enlaces siguen funcionando). Al final de la clase se añadió al menú principal un enlace absoluto a una hija: `<a routerLink="/aula/materiales">Aula > Materiales</a>`.

### Redirección por defecto dentro de children

El apartado 4.3 del enunciado pide que `/aula` lleve directamente a Materiales. Se hace con una ruta vacía al principio de `children`:

```ts
children: [
  { path: '', redirectTo: 'materiales', pathMatch: 'full' },
  { path: 'materiales', component: MaterialesComponent },
  { path: 'avisos', component: AvisosComponent }
]
```

Solo se ve en el enunciado, y el `'full'` sale <Dudoso nota="El final de la línea está cortado en la captura.">cortado</Dudoso>. Aquí `'materiales'` va sin barra: es relativo a `/aula`.

## Marcar el enlace activo

<DeClase fecha="19/11" proyecto="proyecto-rutas" />

`routerLinkActive` añade una clase CSS al enlace mientras su ruta está activa. Acepta `string | string[]`, según el tooltip. Como la clase se usa en varios componentes, va en `styles.css`:

```css title="src/styles.css"
a {
  margin-left: 1rem;
}
.class-css-activo {
  color: yellow;
}
```

Por defecto un enlace se marca si su ruta es **prefijo** de la URL actual: estando en `/aula/materiales`, un enlace a `/aula` también saldría activo. Con `routerLinkActiveOptions` y `exact: true` solo se marca si la URL coincide entera.

<Comparar titulo="routerLinkActiveOptions">
  <Lado tipo="evitar" titulo="Como atributo de texto">

```html
<a routerLinkActive="class-css-activo"
   routerLinkActiveOptions="{exact: true}"
   routerLink="materiales">Materiales</a>
```

Sin corchetes, Angular le pasa **el texto** `"{exact: true}"`, no un objeto. Error **ngtsc(2322)**: *Type 'string' is not assignable to type '\{ exact: boolean; \} | IsActiveMatchOptions'*.

  </Lado>
  <Lado tipo="bien" titulo="Con property binding">

```html
<a routerLinkActive="class-css-activo"
   [routerLinkActiveOptions]="{exact: true}"
   routerLink="materiales">Materiales</a>
```

Con `[ ]`, lo de dentro se evalúa como expresión y llega un objeto.

  </Lado>
</Comparar>

En una captura del minuto 31:34 parece que la versión sin corchetes ya no daba error <Dudoso nota="No es lógico: seguiría llegando como texto. Justo después se escribe con corchetes, que es la versión que vale." />.

## Navegar desde código

<DeClase fecha="19/11" proyecto="proyecto-rutas" nota="minuto 49" />

Además de los enlaces, se puede navegar desde TypeScript inyectando el `Router`:

```ts title="src/app/app.component.ts (49:17)"
export class AppComponent {
  title = 'proyecto-rutas';
  router = inject(Router);
  ngOnInit() {
    //Id que no exist... [comentario cortado]
    this.router.navigate(['/inicio']);
  }
}
```

- `navigate` recibe un **array de segmentos**, como `[routerLink]`: `['/aula/materiales', 7]` iría a `/aula/materiales/7`.
- Es lo que se usa después de guardar o borrar algo, para volver al listado.
- En la línea de `import` de esa captura no se ve `Router` <Dudoso nota="Sale ActivatedRoute y la línea está cortada; el editor marca 2 errores." />: puede que aún faltara importarlo. Para que compile hace falta `import { Router } from '@angular/router'`. El comentario del principio está cortado y no se lee.

## Carga perezosa con loadComponent

<DeClase fecha="27/10" proyecto="angular-http" />

El 27/10, en `angular-http`, ya salió una forma de cargar un componente **solo cuando se visita su ruta**:

```ts title="src/app/app.routes.ts (angular-http)"
export const routes: Routes = [
  { path: '', redirectTo: 'dashboard', pathMatch: 'full' },
  { path: 'dashboard', component: DashboardComponent },
  { path: 'posts', loadComponent: () => import('./pages/posts/posts.component').then(m => m.PostsComponent) },
  { path: 'comments', component: CommentsComponent },
];
```

```html title="dashboard.component.html (fragmento)"
<a class="text-blue-500 cursor-pointer" [routerLink]="['/posts']">Posts</a>
```

- Con `component`, el componente va en el JavaScript inicial de la app. Con **`loadComponent`**, el `import()` dinámico lo separa en otro fichero (*chunk*) que el navegador descarga la primera vez que vas a `/posts`. Lo verás en la pestaña Network.
- `[routerLink]="['/posts']"` es la forma con array. Si falta `RouterLink` en `imports`, sale el error *Can't bind to 'routerLink' since it isn't a known property of 'a'*.
- En `angular-http`, la ruta `posts` sale primero con `loadComponent` y después con `component` <Dudoso nota="No se ve con cuál se queda." />. `RouterLinkActive` se importa ese día pero no se usa.

La Fase VI del enunciado (lazy loading de rutas enteras con `loadChildren` y `AULA_ROUTES`) solo se vio de pasada y muy pequeña: está explicada aparte, en [Parámetros, guards y lazy loading](/docs/2-dam/acceso-a-datos/angular-avanzado/rutas-parametros-guards).

```ts
    ]
  },
  { path: 'ayuda', component: AyudaComponent },
  { path: '**', component: NoEncontradoComponent }
];
```

  Si pones `'**'` al principio, todas las URL coinciden con ella y la app solo enseña la página de no encontrado.

<Ejercicio titulo="Volver al inicio tras una acción" dificultad="facil">
  En `AyudaComponent` añade un botón "Volver al inicio" que navegue a `/inicio` desde TypeScript, sin `routerLink`.

  <Pista>Inyecta el `Router` y llama a `navigate` con un array.</Pista>

  <Solucion>

```ts
import { Component, inject } from '@angular/core';
import { Router } from '@angular/router';

@Component({ selector: 'app-ayuda', templateUrl: './ayuda.component.html' })
export class AyudaComponent {
  private router = inject(Router);

  volver(): void {
    this.router.navigate(['/inicio']);
  }
}
```

```html
<button type="button" (click)="volver()">Volver al inicio</button>
```
