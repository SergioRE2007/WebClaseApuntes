## 2. Conceptos y patrones

- **Delegado**: un tipo que representa una *firma* de método (qué devuelve y qué parámetros recibe). Se declara con `delegate int Operacion(int a, int b);` y cualquier método con esa misma firma se puede guardar en una variable de ese tipo.
- **Dos formas de asignar un método**: `new Operacion(Calculadora.Sumar)` y la forma corta `Operacion op = Calculadora.Sumar;`, que es la que se queda en el código.
- **Invocar el delegado** como si fuera un método: `op(4, 5)`.
- **Reasignar** con `=`: el delegado pasa a apuntar a otro método.
- **Multicast** con `+=`: se añade un método más y, al invocar el delegado, se ejecutan todos en el orden en que se añadieron. En los apuntes también aparece `-=` para quitar uno.
- **Valor de retorno de un delegado multicast**: si se llama directamente con `op(...)`, se ejecutan todos los métodos, pero (en .NET) solo se recibe lo que devuelve el último. Para tener cada resultado se recorre `GetInvocationList()` con `foreach (Operacion operacion in op.GetInvocationList())`.
- **Métodos estáticos y de instancia en un delegado**: un método `static` se pasa con el nombre de la clase (`Calculadora.Sumar`); uno de instancia necesita un objeto (`calc.Restar`). Un mismo delegado puede mezclar los dos tipos.
- **Estado del objeto**: un método de instancia guardado en el delegado puede usar los campos privados del objeto (`val1`, `val2`).
- **Top-level statements**: en `Program.cs` sin `Main`, las instrucciones que se ejecutan tienen que ir antes que las declaraciones de tipos. Si no, sale el error CS8803.
- `int` es un alias de `System.Int32`.
- Interpolación de cadenas con `$"...{variable}..."`.
- Herramientas de Visual Studio que se usan en clase: IntelliSense, tooltips de firma, CodeLens ("N referencias"), resaltado de todas las referencias de un campo, "Mostrar posibles correcciones" (Ctrl+.), consola de depuración y ventana Salida.

## 3. Código del profesor (reconstruido)

### Versión de mitad de clase: métodos estáticos y `foreach`
```csharp
// See https://aka.ms/new-console-template for more information
//Ejecución de la función principal
Operacion op = Calculadora.Sumar;
op += Calculadora.Restar;

// Ejecucion del delegado
foreach (Operacion operacion in op.GetInvocationList())
{
    int resultado = operacion(10, 5);
    Console.WriteLine($"Resultado: {resultado}");
}

// Definiciones
// Funciones
delegate int Operacion(int a, int b);

// Clases
class Calculadora
{
    public static int Sumar(int a, int b)
    {
        int suma = a + b;
        Console.WriteLine($"Suma: {a} + {b} = {suma}");
        return suma;
    }

    public static int Restar(int a, int b)
    {
        int resta = a - b;
        Console.WriteLine($"Resta: {a} - {b} = {resta}");
        return resta;
    }
}
```
Salida:
```
Suma: 10 + 5 = 15
Resultado: 15
Resta: 10 - 5 = 5
Resultado: 5
```

### Versión final: método de instancia y campos privados
```csharp
//Ejecución de la función principal
Operacion op = Calculadora.Sumar;
Calculadora calc = new Calculadora();
op += calc.Restar;

// Ejecucion del delegado
foreach (Operacion operacion in op.GetInvocationList())
{
    int resultado = operacion(10, 5);
    Console.WriteLine($"Resultado: {resultado}");
}

// Definiciones
// Funciones
delegate int Operacion(int a, int b);

// Clases
class Calculadora
{
    private int val1 = 6;
    private int val2 = 3;

    public static int Sumar(int a, int b)
    {
        int suma = a + b;
        Console.WriteLine($"Suma: {a} + {b} = {suma}");
        return suma;
    }

    public int Restar(int a, int b)
    {
        int resta = val1 - val2;
        Console.WriteLine($"Resta: {val1} - {val2} = {resta}");
        return resta;
    }
}
```
Salida:
```
Suma: 10 + 5 = 15
Resultado: 15
Resta: 6 - 3 = 3
Resultado: 3
```

### Ejemplos de los apuntes (PDF)
```csharp
using System;

delegate int Operacion(int x, int y);

class Program
{
    static int Sumar(int a, int b) => a + b;
    static int Restar(int a, int b) => a - b;

    static void Main()
    {
        // 1.4 Asignación y reasignación
        Operacion op = Sumar;                    // Asignar el método Sumar
        Console.WriteLine("Suma: " + op(5, 3));  // Suma: 8
        op = Restar;                             // Reasignar a Restar
        Console.WriteLine("Resta: " + op(5, 3)); // Resta: 2

        // 1.5 Multicasting
        Operacion op2 = Sumar;
        op2 += Restar;                           // Añadir Restar
        foreach (Operacion metodo in op2.GetInvocationList())
        {
            Console.WriteLine(metodo(5, 3));     // 8 y 2
        }
    }
}
```
(En el PDF los dos ejemplos son programas separados y en los dos la variable se llama `op`. Aquí se han juntado en un solo programa y la segunda variable se ha llamado `op2` para que compile.)
